导入微信读书

使用微信读书官方 API Key，选择一本书，预览你的划线和想法。

获取官方 API Key。密钥仅用于本次读取。

    在微信读书网页版打开一本书，进入「笔记」并选择「复制全部笔记」。也可以上传 .txt 或 .md 文件。
    笔记迁移

    导入 flomo

    在 flomo 网页版打开「设置 → 账号详情」，在页面下方导出笔记。选择导出的 ZIP 压缩包或其中的 HTML 文件。

    保留文字、标签和原始记录时间。图片、音频和其他附件会跳过。文件在浏览器里解析，确认后才同步识别出的笔记。

    若导出的时间没有标注时区，会按这里选择的时区读取。
    笔记迁移

    导入 Joplin

    选择 Joplin 导出的 JEX 文件，或 Markdown + Front Matter 文件与目录。预览会列出跳过的附件。

    若导出的时间没有标注时区，会按这里选择的时区读取。
